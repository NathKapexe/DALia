# Reporte Técnico del Proyecto: Dalia (Asistente de Diagnóstico Agrícola)

## 1. Resumen del Proyecto
**Dalia** es una aplicación móvil desarrollada en Flutter apoyada por una arquitectura limpia (Clean Architecture), un servidor backend en Python (FastAPI + PyTorch) y un sistema experto basado en lógica de primer orden (Prolog). Su objetivo es diagnosticar enfermedades y problemas de cuidado en plantas (enfocado inicialmente en cultivos de tomate) combinando la visión artificial (clasificación de imágenes) con un cuestionario de contexto para el usuario.

---

## 2. Arquitectura del Sistema
El proyecto se divide en tres capas principales desacopladas:

### A. Capa Frontend / Móvil (`/app`)
* **Tecnología:** Flutter (Dart).
* **Diseño:** Clean Architecture (Domain, Data, Presentation).
* **Funcionalidad:** Interfaz gráfica para que el usuario capture o elija una foto de su planta[cite: 132], responda preguntas contextuales (estado de la tierra, iluminación y síntomas visuales)[cite: 104, 132] y reciba una lista ordenada de causas probables con sus respectivos tratamientos[cite: 104, 132]. Cuenta con un motor de diagnóstico local que actúa como respaldo si no hay conexión a internet[cite: 160].

### B. Capa Backend / API de Inferencia (`/api`)
* **Tecnología:** Python, FastAPI, PyTorch.
* **Funcionalidad:** Servidor web local que recibe las fotografías de la app, valida su formato/tamaño y utiliza un modelo de inteligencia artificial basado en **MobileNetV2** (entrenado mediante *transfer learning* combinando los datasets *PlantVillage* y *PlantDoc*) para clasificar el estado de la hoja y devolver las confianzas de las 10 clases de tomate[cite: 99, 108, 122].

### C. Sistema Experto Lógico (`/prolog`)
* **Tecnología:** SWI-Prolog.
* **Funcionalidad:** Base de conocimiento estructurada a partir de reglas lógicas (`dalia.pl`) y hechos sobre enfermedades (`hechos_tomate.pl`)[cite: 159, 165]. Evalúa las evidencias visuales del modelo y las respuestas del usuario mediante backtracking y cálculo de puntajes ponderados para arrojar un diagnóstico formal validado mediante pruebas unitarias (`plunit`)[cite: 159, 160, 165].
