# 🍅 DALia — Guía de Arranque en Teléfono (Modo Red Local)

Esta guía detalla los pasos para ejecutar la interfaz de **DALia** en un teléfono celular (vía navegador web en red local) mientras el servidor de inferencia (FastAPI + PyTorch + SWI-Prolog) corre en la computadora.

---

## 📋 Requisitos Previos

- **Computadora:** Python (entorno `.venv` configurado en `/api`) y Flutter SDK instalados.
- **Red:** La computadora y el teléfono deben estar conectados exactamente a la **misma red Wi-Fi**.
  > 💡 **Tip para redes escolares/públicas:** Las redes institucionales suelen bloquear la comunicación directa entre dispositivos (*AP Isolation*). Si estás fuera de casa, activa el **Hotspot / Zona Wi-Fi** de tu teléfono y conecta tu laptop a esa red.

---

## Paso 0: Obtener la IP de la computadora

La dirección IP cambia cada vez que te conectas a una red Wi-Fi distinta, por lo que siempre debes verificarla antes de iniciar:

1. Abre una terminal en Windows (**CMD** o **PowerShell**).
2. Ejecuta:
   ```cmd
   ipconfig
   ```
3. Busca el bloque de tu red actual (`Adaptador de LAN inalámbrica Wi-Fi`) y anota el valor de **Dirección IPv4** (por ejemplo: `172.20.10.2` o `192.168.1.75`).
4. A este valor lo llamaremos `TU_IP` en los siguientes pasos.

---

## Paso 1: Encender el Servidor Backend (Terminal 1)

Esta terminal mantiene activo el motor de diagnóstico (visión artificial + sistema experto).

1. Abre una terminal en Visual Studio Code (**CMD** o **PowerShell**) y entra a la carpeta `api`:
   ```cmd
   cd api
   ```
   *(O usa la ruta completa: `cd C:\Users\Gaby\Desktop\DALia1.0\DALia\api`)*

2. Activa el entorno virtual de Python:
   - En **CMD**:
     ```cmd
     .venv\Scripts\activate
     ```
   - En **PowerShell**:
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   *(Sabrás que está activo cuando veas `(.venv)` al inicio de la línea).*

3. Inicia Uvicorn escuchando en toda la red local (`0.0.0.0`):
   ```cmd
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```
   *(Si tu archivo principal está dentro de `src`, usa `uvicorn src.main:app --reload --host 0.0.0.0 --port 8000`).*

4. Espera a ver el mensaje `Application startup complete.` y deja esta terminal abierta.

---

## Paso 2: Encender la App Frontend (Terminal 2)

Esta segunda terminal sirve la interfaz de Flutter hacia tu teléfono apuntando a la API de Python.

1. Abre una segunda terminal en VS Code presionando el botón **`+`** (arriba a la derecha del panel de terminales).
2. Entra a la carpeta `app`:
   ```cmd
   cd app
   ```
   *(O usa la ruta completa: `cd C:\Users\Gaby\Desktop\DALia1.0\DALia\app`)*

3. Ejecuta el servidor web de Flutter reemplazando `TU_IP` por tu IPv4 del Paso 0 (sin dejar espacios después de `http://`):
   ```cmd
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080 --dart-define=DALIA_API_URL=http://TU_IP:8000
   ```
   Ejemplo real:
   ```cmd
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080 --dart-define=DALIA_API_URL=[http://172.20.10.2:8000](http://172.20.10.2:8000)
   ```
4. Espera a que aparezca: `lib\main.dart is being served at http://0.0.0.0:8080`.

---

## Paso 3: Abrir DALia en el Teléfono

1. Abre el navegador de tu celular (**Chrome**, **Safari**, **Brave**, etc.).
2. En la barra de direcciones, entra a `TU_IP` con el puerto `:8080`:
   ```text
   http://TU_IP:8080
   ```
   Ejemplo real: `http://172.20.10.2:8080`

¡Listo! Ya puedes tomar fotografías con la cámara o seleccionar imágenes de la galería para diagnosticar hojas de tomate.

---

## 🔌 Guía Rápida de Puertos

| Puerto | Servicio | ¿Se abre en el teléfono? |
| :--- | :--- | :--- |
| `:8000` | Backend FastAPI (Python) | ❌ No. Si lo abres verás `{"detail": "not found"}`. |
| `:8080` | Interfaz DALia (Flutter) | ✅ Sí. Esta es la dirección de la aplicación. |

---

## 🛑 Cómo apagar los servicios al terminar

1. Haz clic en la **Terminal 2 (Flutter)** y presiona la tecla **`q`**.
2. Haz clic en la **Terminal 1 (Python)** y presiona **`Ctrl + C`**.
